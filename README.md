# 时栖时钟 0.5.13

时栖时钟（ShiqiClock，`com.foldstandby.clock`）的产品方向是面向各种机型的桌面时钟。「时栖」取时间在桌面停驻之意，以安静、清晰与陪伴作为品牌表达。最低支持 Android 11（`minSdk 30` / `targetSdk 33`），当前版本 `0.5.13`（`versionCode 33`）。

- **组件与样式**：内置 10 类组件（时钟、日历、日程、天气、音乐、专注、电量、世界时钟、待办、闹钟），共 51 种视觉样式（时钟 6 种，其余 9 类各 5 种），支持整屏 / 双栏 / 主次 / 四格页面布局、纯黑底色、6 种主题渐变与分层日夜配色。
- **自适应工作台**：可隐藏抽屉导航、手表透视页面轮播、内容/外观/配色一体化工作台、自适应列数的样式/组件画廊、多步撤销与 5 个本地恢复点。
- **独立待办与提醒**：多清单、9 大视图、重复规则、子任务、到期提醒通知与锁屏隐私开关，横竖屏与折痕自适应双栏浏览及编辑。
- **多形态待机**：支持手动开始待机、充电静置自动待机及折叠屏帐篷/支架姿态识别；自动避让系统安全区与物理折痕，窄小窗口自动分拆临时子页，竖向受限窗口内时钟画布固定顺时针旋转 90°。

## 目录结构

- `app/src/main/java/com/foldstandby/clock/`：应用主源码（工作台与导航 `MainActivity`、待机渲染 `ClockActivity` / `ClockStage` / `ClockFace` / `ClockLayout` / `Sandglass`、自适应策略 `AdaptiveLayout`、待办系统 `TodoActivity` / `TodoEditor` / `TodoStore` / `TodoViewport` / `TodoReminders`、姿态与外屏门限 `StandbyService` / `PostureGate` / `ChargingStandbyGate` / `Fold` 等）。
- `app/src/androidTest/java/com/foldstandby/clock/`：设备端 instrumentation 检查套件（入口 `DeskChecks`）。
- `tests/`：纯 Java 单元测试及真机截图/QA 导出脚本（`ExportQa.ps1`、`Snapshot.ps1`）。
- `tools/render_branding.py`：从 Android 矢量资源导出品牌预览图与 PNG/SVG 图标（需要 Pillow）。
- `third_party/fold-toggle/`：第三方开源许可与外屏控制原始来源（详见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)），核心术语定义见 [GLOSSARY.md](GLOSSARY.md)。
- `releases/`：仅包含各版本正式 APK 安装包的专用下载目录。
- `dist/`：各版本正式/调试安装包、验证记录与截图存档。

## 使用

- **长按跨页排序**：在页面预览上长按后，将手指移到列表顶部或底部附近即可持续滚动；停留在边缘也会继续滚动，可一次从末页拖到首页或反向拖动。松手应用顺序，主页跟随页面身份保留。
- **待办管理**。从主导航进入「待办管理」，或从桌面待办直接新增、勾选和打开详情。「今天」显示当天事项，完成后划线并排到未完成事项下方，再点勾选区可以取消完成。未来日期在「计划」，过期事项通过「已过期」入口查看，无日期事项可以单独展开。宽横屏采用双栏，管理页并排显示导航和事项，新增与编辑页并排显示标题日期和详细设置。竖屏用顶部快捷按钮切换今天、计划和未安排。
- **整理与找回**。点事项的更多按钮编辑、改期、归档或删除，长按可以多选。已完成和手动归档的事项各有入口。删除时可撤销，回收站保留 30 天，并支持恢复及永久删除。
- **更大的预览与自动保存**：页面预览按当前窗口的横屏比例与工作台可用空间放大，横屏扩大左侧预览区、竖屏扩大固定预览区域，并保留少量边距。移除工作台重复的全屏、设置、日夜和保存／取消按钮；全局操作统一收进导航。有效编辑自动保存，表单仍需确认添加或修改，未完成的 HEX 输入不会覆盖最后的有效颜色。命名场景仍可另存快照。
- **左侧导航**：横屏展开时占用布局空间，竖屏从左侧覆盖主页面；收起或系统返回键关闭，竖屏也可点击遮罩关闭。导航内容可独立滚动。

- **闹钟组件**：提供极简闹钟、唤醒表盘、剩余时间、闹钟卡片和响铃时刻尺，接入样式库和编辑器、75%–125% 大小、纯黑底、渐变、分层配色、夜间模式与页面布局。显示系统报告的下一次响铃时间，可独立开关日期、剩余时间和 24 小时制。组件编辑卡片及「设置 → 组件数据」可添加、管理系统闹钟；全屏轻触打开对应闹钟，未设置时打开新增页面，锁屏按系统要求解锁。新增页面由系统时钟填写时间、重复、铃声和稍后提醒，响铃也由系统负责。系统闹钟变化、时间／时区变化及返回应用时自动刷新；无闹钟与不可用时有独立提示。场景保存显示设置，所有场景共用系统闹钟。仅使用系统下一次闹钟接口，不读取完整列表、名称或重复规则；时钟应用未向系统报告的闹钟无法显示。

- **自然流沙与翻转复位**：沙漏按剩余时间计算上下沙量；上层沙面逐渐下降并形成中央漏斗，下落沙粒随重力加速，下层沙堆升高并沿两侧自然滑落。长按重置、调整专注时长、计时完成后重新开始都会触发归沙、180° 翻转与沉降，转动中沙子随重力方向重新分布。样式预览演示完整的流尽与翻转周期，实际计时遵循设置的时长。暂停后停沙，夜间、休眠或关闭动效时停止动画。电量光点保留连续整圆轨迹。

- **全部组件均有多种视觉样式**：时钟提供六种表盘，其余九类组件各有五种。在「外观 → 更换外观」中点击预览即可应用。样式随场景保存、复制和恢复，切换组件类型会记住各类组件上次使用的样式。更换外观保留事项、城市、时区、内容开关、大小及配色。昼夜轨道和时带按当地 06–18 时标记日间。
- **音乐外观**：黑胶和卡带各有写实与矢量样式。写实样式保留材质色，矢量样式用低饱和的石墨底色和细线呈现结构。标签细节与机械点缀跟随主题配色，两款卡带都在标签上显示当前曲名。播放时唱片转动、唱臂随进度内移、卡带卷盘随卷径转动。「内容」中的第三方实时频谱默认关闭，用户可主动开启并授权系统播放输出分析。夜间模式或关闭动效时可查看静态外观。
- **同步歌词**：在音乐组件的「内容」中为当前曲目导入本地 LRC，再在「外观」打开「显示歌词」。五种样式共用这个开关，宽预览可同时显示下一句。歌词随播放位置更新，缺少歌词时显示曲目信息。

- **统一深色输入表单**：待办添加／修改、页面／场景名称、天气城市搜索与结果、经纬度、世界时区搜索统一使用圆角深色表单、薄荷绿主按钮与焦点边框，错误在字段下方显示。键盘支持搜索／完成／下一项，横屏保留应用表单，旋转保留正在输入的内容；HEX 输入采用相同焦点样式。待办仍在程序内管理。
- **极简可隐藏导航与全屏画布**：默认隐藏常驻顶栏与侧栏，通过左上角「☰」展开/收起导航抽屉（含场景切换 `时栖 / <场景名> ▾`、页面工作台、待机控制与六大设置分类、全屏预览与日夜切换）。
- **智能手表式页面透视轮播（唯一实时预览）**：去掉重复的双预览与多余卡片底座，使用当前窗口横屏比例的纯黑预览框；当前选中页居中放大、高亮边框并支持直接点击表盘内分栏切换槽位，上下未选中页按 3D 透视比例缩小淡化，长按可拖动排序。滑动时顶部「场景页面」与底部「＋ 添加页面」固定不动，仅中间页面列表滑动并自动居中吸附。
- **样式 · 编辑 · 配色 · 页面一体化工作台**：点击任意页面缩略图不再跳转离开，直接联动工作台中的「样式」「编辑」「配色」「页面」四个子面板；**横屏**下左轮播、右工作台平行并排展示；**竖屏**下将页面轮播固定在屏幕上方，下方参数/调色区独立滚动，滑动参数时预览始终不移出屏幕，点击「样式」则打开自带实时预览卡片的二级全屏样式库并支持返回工作台。
- **紧凑字号与双向字体缩放**：整体收紧工作台与表单字号及行高；「设置 → 显示与夜间」新增**界面与文字大小**（小 85% / 标准 100% / 大 115% / 特大 130%），且**全部十类组件**均支持在编辑面板独立调节**显示大小**（75%–125%）。
- **全组件渐变与实色胶囊调色板**：`纯色 / 极光 / 晨曦 / 海洋 / 莓果 / 金霞` 渐变扩展至**全部十类组件**的主视觉元素（数字、翻页、数码、点阵、指针/小时刻度、日历当日圆标、日程/待办正文、天气大温度、专注/电量进度圆环与闪电图标、音乐进度条与主播放按钮）；「配色」面板中的预设搭配、主题渐变、自定义颜色角色与最近使用全部采用**颜色直接填充按键底色**的高紧凑胶囊按钮，内置作用域切换（场景 / 此页 / 此组件 / 夜间）、HSV 调色盘与 HEX 输入。
- **纯黑组件**：全部组件及新旧主题统一使用 `#000000` 背景，包括指针盘和翻片；保留文字、指针、刻度、结构线的配色。旧版纸白/奶油整套主题自动转换为适合黑底的浅色文字。
- **指针盘**：时/分刻度独立显隐，调整长度与粗细；数字可选无、四方向、全部、罗马数字；秒针跳动或平滑运行。
- **页面过渡**：全屏预览与待机支持纵向滑动、柔和淡化和关闭动画，速度可选轻快/自然/舒缓（默认 360ms）。连续滑动保留当前过渡位置，自动轮播跨末页保持前进方向，闲置回主页直接淡化。设置 → 页面与轮播可配置；遵从系统关闭动画。
- **电量**：环形电量仪表、百分比、供电状态和电池温度。实际充电时有沿环流动的能量动画，充满/暂停充电/夜间/休眠时停止；设置可关闭动态效果。
- **浏览**：上滑下一页、下滑上一页。默认闲置60秒回主页，可调整或关闭。自动轮播默认关闭，开启后触摸会暂缓轮播。全屏不再显示底部工具栏，使用系统返回键或返回手势退出。
- **场景与控制中心**：「☰ → 设置」支持启停充电与折叠姿态自动待机、配置夜间时段（独立配色、亮度、暖红预设及按需息屏查看时长 10/20/30/60 秒）与场景保存/载入/恢复模板。从旧版升级后可在「自动待机」开启所需触发方式。
- **帐篷与支架自动识别，无需校准**：默认同时识别帐篷、左右反向、横竖支架和小角度悬停，一半平放作底座也可识别。半折支起、锁屏并静置约 3 秒后自动进入外屏时钟；时钟保持横屏，由系统横屏方向传感器选择正向或反向，避免用底座半屏的重力 X 轴强制翻转。两个姿态类别可在「设置 → 自动待机」独立启停。旧的单方向校准不再限制触发。过滤合拢、完全展开和持续移动；姿态采样以固定方向为基准累计变化，避免慢速移动被当作静置。系统将外屏切为主屏后才启动时钟；尚未就绪时保持监测，在检测状态中提示合拢后重新支起。

## 数据与操作

天气检查整个场景中的组件需求，可在天气组件编辑卡片或「设置 → 组件数据」点击「使用当前位置」：首次请求系统近似定位权限，仅在点击时获取一次位置并保存天气地点，移动后可再次点击更新；不请求精确或后台定位。系统无法返回城市名称时显示「当前位置」，仍按坐标获取天气。也可搜索城市或按经纬度设置；搜索兼容简体、繁体和英文，服务返回的中文地名及旧版已选城市统一显示简体（例如「西雅图」）。天气来自 Open-Meteo，提供实况、体感、湿度、最高/最低温及明日选项。天气成功后按 15 分钟间隔刷新，失败从 1 分钟起退避重试，继续显示缓存。网络任务与日历任务分离。日历支持「月历＋今日事项」与纯月历；日程可选择今天或接下来 24 小时。日程需日历权限，默认锁屏隐藏具体内容。音乐需通知使用权，仅读取媒体会话，不读取通知正文；新界面提供封面、曲目信息、时间进度、独立上一首/播放暂停/下一首圆形矢量按钮及按压反馈。按钮按播放器声明的操作能力启用，支持无障碍操作；封面、进度和控制能力取决于播放器。

待办清单在本机独立保存。同一清单可在多个场景显示，恢复场景时继续使用清单的最新状态。升级会将现有待办迁为独立清单并保留完成状态，旧快照里的任务可从「待办管理 → 视图 → 旧待办迁移记录」导入为副本。锁屏默认隐藏任务内容。在「设置 → 数据与权限」打开锁屏待办后，可在锁屏上添加、完成和管理任务。数字、数码和点阵的秒数与主时间同排，保持各自字形。

专注组件下半部轻触开始/暂停，长按重置，或从设置重置。它是屏幕倒计时，不是后台闹钟，应用关闭后不保证发声。世界时钟可搜索 IANA 时区。

场景保存全部页面、主页、布局、组件、主题、样式及参数。数据源、权限、隐私、亮度、界面字号、息屏与轮播策略为全局设置。

## 真机与限制

最低支持 Android 11。早期外屏姿态验证设备为 SM-F971U1 / Android 17，历史检查结果见 dist/VALIDATION-0.3.2.md。

夜间休眠暂停主动唤醒与高频姿态监听，等待系统唤醒或离开本次姿态。系统双击需用户开启，外屏恢复依赖系统路由。当前没有摄像头权限或注视识别。

自动支架检测依据铰链、重力方向、锁屏与静止时间，不直接感知是否接触桌面；手持完全不动也可能满足条件。半折范围为传感器读数 5°–170°；重力传感器位于其中一半，该半屏平放时仍可能是有效支架底座，因此不把单个重力方向接近平放作为否决条件。Fold8 的公开铰链读数在本机呈现 0° / 90° / 180° 档位，无法据此精确区分所有实际小角度；系统仍报告合拢时不会强行点亮。外屏切换能力取决于设备和系统策略。

常亮、传感器监控和 CPU 保活会增加耗电，并非系统原生低功耗 AOD。微移、低亮和温控只能降低负担，不能保证无烧屏；没有整晚耗电或长期老化实测。无账号、广告、遥测。
